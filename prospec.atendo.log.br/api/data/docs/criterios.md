# Critérios de Classificação

## Tipos de Termos
| Tipo | Descrição | Exemplo |
|------|-----------|---------|
| nome_oficial | Nome oficial da subclasse | "Cultivo de arroz" |
| sinonimo | Sinônimo do termo oficial | "Plantio de arroz" |
| termo_popular | Termo usado no dia a dia | "Arrozicultura" |
| regionalismo | Variante regional | "Arrozeiro" |
| abreviacao | Abreviação comum | "Arroz" |
| atividade | Atividade descrita | "Plantio" |
| servico | Serviço oferecido | "Consultoria agrícola" |
| produto | Produto fabricado/vendido | "Arroz integral" |
| profissao | Profissão associada | "Arrozeiro" |
| palavra_chave | Palavra-chave genérica | "Agricultura" |

## Origem dos Termos
| Origem | Descrição |
|--------|-----------|
| descrição oficial | Extraído da descrição oficial do IBGE |
| linguagem popular | Termo de uso corrente no mercado |
| classificação semântica | Inferido pela análise semântica da descrição |
| mercado | Termo identificado no mercado |
| pesquisa comum | Termo frequentemente pesquisado |

## Critérios de Relevância
- 100: Nome oficial exato da subclasse
- 90: Descrição completa como termo
- 85: Palavra-chave extraída da descrição
- 75: Sinônimos e variantes
- 60: Termos populares e regionalismos
- 50: Termos relacionados indirectamente
